# Investment Research Links


# 企业信息与合规披露
[巨潮资讯网](https://www.cninfo.com.cn/new/index)：上市公司财报、公告、问询函首发
[国家企业信用信息公示系统](https://gd.gsxt.gov.cn/subPubSys-440000.html)：企业工商、年报、司法、经营异常
[同花顺快查](https://www.kuaicha365.com/outer/)：企业背景、风险、股权结构、招投标
[启信宝](https://www.qixin.com/)：企业全景、司法风险、股权穿透、舆情


#行业与宏观数据
[东方财富网（数据中心）](https://data.eastmoney.com/center/)：行业营收 / 毛利、竞争格局、北上资金、机构调研
[萝卜投研](https://robo.datayes.com/)：券商研报、行业数据、财报一键解读
[国家统计局](https://www.stats.gov.cn/)：GDP、CPI、PMI、行业产值、统计年鉴
[中国人民银行官网](https://www.pbc.gov.cn/)：LPR、利率、汇率、货币政策、国债收益率曲线


#量化与数据接口

[Tushare Pro](https://tushare.pro/)：A 股行情、财务、基金数据 API
[同花顺 iFinD（需下载）](http://www.aifind.com/)：智能问财选股、深度资料、行业数据
